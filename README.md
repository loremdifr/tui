## tui.h - C23 TUI framework

Immediate mode, STB-style TUI framework for writing small C apps.

Currently targeting only Linux. Modern Windows support coming soon.

## WINDOWS

```cmd
gcc -fdiagnostics-color=always -W -Werror -Wextra -pedantic -g -std=gnu23 -Ilibs main.c -o build/main.exe -lm
```
